Abstract

Fingerprint foreground segmentation affects every downstream operation that depends on ridge-bearing area. We benchmark the segmentation methods catalogued in a recent review using a single subject-disjoint split, common resolution and common metric implementation. Examiner ROI polygons define the primary latent endpoint; usable-ridge maps provide a second GT definition; expert-minutiae hulls support a lower-bound exemplar analysis without pretending to be full masks. Hyperparameters and thresholds are selected on validation data, final test scoring is locked, and uncertainty is estimated by subject-cluster bootstrap with multiplicity-corrected paired tests. This public site contains aggregate results and synthetic illustrations only. Licensed biometric samples, per-image records and trained weights are not distributed.

The problem

Background texture can create false ridge evidence; overly tight masks can remove usable minutiae. The benchmark measures both missed foreground and false background detection while preserving the distinction between an examiner ROI and a usable-ridge map.

Reproducibility

No script downloads biometric data. Supply locally authorised paths and frozen receipts.

python -m pip install -r requirements.txt
python scripts/smoke_synthetic.py --work-dir .smoke
bash scripts/reproduce_table_A.sh --config local/benchmark.env
python site/build.py
python scripts/check_site_numbers.py
python scripts/scan_release.py

Limitations

Reimplementations can differ from original code; SegFormer is a declared substitute; released zero-shot models have external training provenance; ROI and usable-ridge GT answer different questions; exemplar hulls are lower bounds; and one coordinated data source cannot establish every deployment domain.
